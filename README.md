# Restaurante Bernardo Monteiro

Site institucional responsivo em HTML, CSS e JavaScript, com GSAP 3.13 e ScrollTrigger via CDN.

## Visualizar

Abra `index.html` diretamente no navegador ou sirva a pasta com um servidor estático.

## Antes de publicar

- Substitua o endereço, telefone, e-mail e horários provisórios.
- Atualize os links do WhatsApp e redes sociais.
- Para envio do formulário sem abrir o aplicativo de e-mail, conecte o formulário a um serviço de backend.
- Troque as imagens em `assets/` mantendo os mesmos nomes, ou atualize os caminhos no HTML.

As duas imagens atuais foram criadas especificamente como materiais provisórios para esta proposta.
